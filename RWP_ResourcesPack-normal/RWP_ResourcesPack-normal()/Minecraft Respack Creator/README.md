# Usage for Minecraft Respack Creator (Item)

> [!CAUTION]
>
> 注意：这个工具只能帮你创建物品以及其对应的模型映射（方块等不适用）
> This tool can only build&create items for its model.

1. Make sure you have put the items in the same folder.
确保你把所有要创建模型映射的物品的材质图片都放在一个文件夹下。
2. input the folder's path
输入这个文件夹的路径，工具会自动寻找文件夹下对应的png图片。
3. input the output folder's path you want to set
指定资源包的输出路径
4. assign the id for your respack
指定资源包的命名空间id

5. Just do it.
确认无误后，回车即可创建物品对应资源包。
