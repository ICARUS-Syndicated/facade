# This is the Resourcepack for RWP server

To collaborate with the datapack and formed a unified game work, we created this resourcepack.

So the things in datapack **may use models/textures in this resourcepack**, such as `rwp:mooncake`, `unframed:item_frame` etc.

For how to deploy this resourcepack on the server, you may use [This tool](https://github.com/RWPteam/ResourcePackUpdateTool) developed by @samu1oto.
